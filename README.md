## 预测模型

### 1. XGBoost 回归模型
- 对每个号码位置训练一个 XGBoost 回归器
- 特征: 历史 20 期号码、和值、奇偶比、跨度、频率统计
- 输出: 每个位置的号码预测值(回归到合法范围)

### 2. MLP 神经网络 (纯 numpy 实现)
- 三层全连接网络: 输入 → 128 → 128 → 输出
- 激活函数: ReLU + Softmax
- 损失函数: 多分类交叉熵
- 输出: 每个号码位置的概率分布
- 不依赖 tensorflow/pytorch，部署轻量

### 3. 随机森林 (Random Forest)
- 对每个号码位置训练一个 RandomForestClassifier (80棵树)
- 特征: 历史 15 期 + 频率 + 和值/跨度
- class_weight='balanced' 处理类别不平衡

### 4. 马尔可夫链 (Markov Chain)
- 每个号码位置一个状态转移矩阵
- 1阶 + 2阶马尔可夫混合 (0.7×1阶 + 0.3×2阶)
- Laplace 平滑避免零概率

### 5. 朴素贝叶斯 (Naive Bayes)
- 对每个号码训练一个 MultinomialNB 二分类器
- 特征: 历史 10 期出现情况
- 输出: 每个号码的出现概率

### 6. 蒙特卡洛模拟 (Monte Carlo)
- 基于近 50 期频率分布构建概率模型
- 5000 次模拟采样 (可重复/不可重复两种模式)
- 取模拟中出现频率最高的号码

### 7. K-Means 聚类
- 对历史期号进行 one-hot 聚类 (8 个簇)
- 找到最近一期所属簇
- 用该簇内号码频率分布预测

### 8. LSTM 时序网络 (纯 numpy 实现)
- 完整 LSTM 单元: 输入门/遗忘门/输出门
- seq_len=10, hidden_size=32, epochs=15-20
- 梯度裁剪 + Adam 优化器
- 不依赖 tensorflow/pytorch

### 9. 传统统计策略
- **热号推荐**: 基于最近 30 期号码频率
- **冷号回补**: 基于号码遗漏值
- **综合推荐**: 频率 + 遗漏 + 转移概率综合打分
- **随机机选**: 加权随机采样(参考综合评分)

### 10. Stacking 元学习器
- LogisticRegression 元学习器组合所有基础模型
- 元特征: 每个基础模型对每个号码的概率
- class_weight='balanced'

## 自动化流程

GitHub Actions 每天北京时间 08:00、23:00 自动执行（也支持 push / 手动触发）:

1. **抓取数据** - `python3 scripts/update_data.py` (主源失败自动降级 500.com)
2. **训练模型** - `python3 scripts/train_models.py`
3. **检查上次预测命中** - `python3 scripts/check_hits.py`
4. **更新动态权重** - `python3 scripts/update_weights.py` (基于历史回测)
5. **生成新预测** - `python3 scripts/predict.py`
6. **权重融合预测** - `python3 scripts/weighted_predict.py` (综合所有算法)
7. **历史回测验证** - `python3 scripts/backtest.py`
8. **归档预测历史** - `python3 scripts/update_history.py` (结算已开奖 + 归档新预测)
9. **更新 README** - `python3 scripts/generate_readme.py` (下一期预测)
10. **更新历史文件** - `python3 scripts/generate_history.py` (docs/prediction-history.md)
11. **提交推送** - 自动 commit 并 push 到 GitHub

也可手动在 GitHub Actions 页面触发运行。

## 本地运行

```bash
# 安装依赖
pip install -r requirements.txt

# 抓取最新数据
python3 scripts/update_data.py

# 训练所有模型
python3 scripts/train_models.py

# 训练单个彩种(如双色球)
python3 scripts/train_models.py ssq

# 生成预测
python3 scripts/predict.py

# 检查上次预测命中情况 (永久记录命中)
python3 scripts/check_hits.py

# 更新动态算法权重 (基于历史回测)
python3 scripts/update_weights.py --backtest 20

# 权重融合预测 (综合所有算法)
python3 scripts/weighted_predict.py

# 历史回测验证 (启用所有算法)
python3 scripts/backtest.py --n 30

# 历史回测验证 (跳过慢速模型加速)
python3 scripts/backtest.py --n 30 --no-slow

# 更新动态权重 (启用所有算法, 慢)
python3 scripts/update_weights.py --backtest 20

# 更新动态权重 (跳过慢速模型, 快)
python3 scripts/update_weights.py --backtest 20 --skip-slow

# 生成 README
python3 scripts/generate_readme.py

# 交互式菜单
python3 main.py
```
