# 超级大乐透（DLT）规则与分析

规则版本：2026 年新规，自第 26014 期（2 月 2 日）起执行，共七个奖级。

## 号码与投注

前区 1–35 选 5 个不同号码，后区 1–12 选 2 个不同号码，区内顺序不限。基本投注每注 2 元，可加 1 元追加。每周一、三、六开奖，休市除外。支持单式、前区/后区/双区复式、胆拖和倍投。复式注数=C(f,5)×C(b,2)。

## 奖级

| 奖级 | 前区+后区命中 | 奖池低于8亿 / 达到8亿 |
| --- | --- | --- |
| 一等 | 5+2 | 浮动 |
| 二等 | 5+1 | 浮动 |
| 三等 | 5+0、4+2 | 5000 / 6666 元 |
| 四等 | 4+1 | 300 / 380 元 |
| 五等 | 4+0、3+2 | 150 / 200 元 |
| 六等 | 3+1、2+2 | 15 / 18 元 |
| 七等 | 3+0、2+1、1+2、0+2 | 5 / 7 元 |

追加只参与一、二等奖，额外奖金为对应基本投注浮动奖的 80%，不会增加覆盖的号码组合。一等奖存在分部计奖，一般基本投注最高可达 1000 万元，基本加追加最高 1800 万元，仍受封顶和风险控制约束。一、二等奖奖金总额单期分别封顶 1 亿元。

## 概率与选择依据

总基本投注数 C(35,5)×C(12,2)=21,425,712；一等奖概率 1/21,425,712；任一奖约 6.6705%。名义奖金计提 51%（49% 当期、2% 调节基金）。

奖池低于 8 亿时固定奖部分每注期望约 0.5550 元。若基本投注浮动奖期望为 F、固定奖期望为 K，则基本每元返还=(F+K)/2，追加后=(1.8F+K)/3。只有 F>1.25K 时，追加才提高每元期望；不能凭一段历史平均奖金断言追加总是划算或总是不划算。

偏好乐透大奖时可考虑基本单式；奖池是否达到 8 亿会改变固定奖金，但不能仅凭奖池水位证明完整回报更高，更不能证明下一期号码可预测。

## 历史预测的适用边界

修复前的位置型数据被排序，且同期开奖的多个模型输出相互相关。旧命中率、基于这些输出的 z 检验和“显著优于/差于随机”的结论不能证明预测能力。修复后重新抓取原始顺序、训练、预测并积累逐期样本，旧记录隔离保存。乐透彩种也不能把“至少中一个号码”当成实际中奖率。

## 长期维护

本文为规则说明，不随每日 Actions 覆盖。规则、派奖或奖金表可能变更，应按官方公告的生效期版本更新。奖金为税前规则金额；浮动奖金和特别活动不能视为固定回报。复式只是购买多注组合，在奖金结构不变时不改善单位成本的数学期望。
