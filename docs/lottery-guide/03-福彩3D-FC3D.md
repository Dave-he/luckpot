# 福彩3D（FC3D）规则与分析

依据中福彩中心公布的 3D 游戏规则；下述扩展玩法是否销售应以所在地福彩机构为准。

## 号码与投注

三个有序位置：百位、十位、个位，每位 0–9，允许重复与前导零。每天开奖，休市除外，每注 2 元。单选必须保留原顺序；组选只在明确购买组选玩法时忽略顺序。不能把单选号码排序后判奖。

## 核心玩法

| 玩法 | 中奖条件 | 单注奖金 | 单注概率 | 税前期望返还 |
| --- | --- | --- | --- | --- |
| 单选 | 三位按位全同 | 1040 元 | 1/1000 | 1.040 元 |
| 组选三 | 指定两同一异组合，顺序不限 | 346 元 | 3/1000 | 1.038 元 |
| 组选六 | 指定三个不同数字，顺序不限 | 173 元 | 6/1000 | 1.038 元 |

组三和组六的概率是针对已选定的一注组合；豹子不属于组三或组六。核心玩法每注期望净收益约 -0.96 元。名义奖金计提比例 53%（52% 当期、1% 调节基金）不是每注返还 53%。

| 玩法 | 判定方式 | 奖金 |

| 1D | 指定一位及数字 | 10 元 |
| 猜1D | 数字在任意位置出现1/2/3次 | 2 / 12 / 230 元 |
| 2D | 指定两位按位命中 | 104 元 |
| 猜2D | 两同号 / 两不同号包含于开奖号 | 37 / 19 元 |
| 通选 | 按位全中 / 恰中两位 | 470 / 21 元 |
| 包选三 | 指定排列全中 / 其余排列组中 | 693 / 173 元 |
| 包选六 | 指定排列全中 / 其余排列组中 | 606 / 86 元 |
| 和数 | 三位之和等于指定和值 | 见下表 |
| 猜大小 | 和值0–8为小，19–27为大，选一边 | 6 元 |
| 猜三同 | 任意豹子 | 104 元 |
| 拖拉机 | 升/降连续三位，不含890、098、901、109 | 65 元 |
| 猜奇偶 | 全奇或全偶，选一边 | 8 元 |

同一张扩展玩法的多个中奖情形必须合计后计算期望。例如猜1D期望=0.243×2+0.027×12+0.001×230=1.040元；通选=0.001×470+0.027×21=1.037元；包选三=1.039元、包选六=1.036元。此前只把某个奖档当成完整玩法，声称这些玩法返奖率低至16%–35%，该结论错误，已撤回。

## 历史预测的适用边界

修复前的位置型数据被排序，且同期开奖的多个模型输出相互相关。旧命中率、基于这些输出的 z 检验和“显著优于/差于随机”的结论不能证明预测能力。修复后重新抓取原始顺序、训练、预测并积累逐期样本，旧记录隔离保存。乐透彩种也不能把“至少中一个号码”当成实际中奖率。

## 长期维护

本文为规则说明，不随每日 Actions 覆盖。规则、派奖或奖金表可能变更，应按官方公告的生效期版本更新。奖金为税前规则金额；浮动奖金和特别活动不能视为固定回报。复式只是购买多注组合，在奖金结构不变时不改善单位成本的数学期望。
