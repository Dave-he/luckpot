# 七乐彩（QLC）规则与分析

依据中福彩中心七乐彩游戏规则。

## 号码与投注

从1–30选7个不同号码，每注2元，顺序不限，每周一、三、五开奖。开奖先取7个基本号，再从剩余号码中取1个特别号。特别号是开奖角色，购彩者只选7个号码，不能额外另买一个“蓝球”。仓库blue1字段表示特别号，不能按双色球蓝球的方式判断。

支持单式、8–16号复式、1–6胆码的胆拖、倍投。选r个号时注数=C(r,7)。

## 奖级

| 奖等 | 命中条件 | 奖金 |
| --- | --- | --- |
| 一等 | 7基本号 | 浮动 |
| 二等 | 6基本号+特别号 | 浮动 |
| 三等 | 6基本号、不含特别号 | 浮动 |
| 四等 | 5基本号+特别号 | 200 元 |
| 五等 | 5基本号、不含特别号 | 50 元 |
| 六等 | 4基本号+特别号 | 10 元 |
| 七等 | 4基本号、不含特别号 | 5 元 |

一、二、三等奖分配当期高等奖奖金的70%、10%、20%；单注最高500万元。名义计提奖金50%（49%当期、1%调节基金）。

## 概率与选择依据

投注组合数=C(30,7)=2,035,800，一等奖概率1/2,035,800。若计算完整“基本号+特别号”的开奖空间，则为C(30,7)×23=46,823,400，一等奖对应其中23种开奖事件；不可误称彩票有4682万种投注组合。

任一奖概率约3.3137%，固定奖部分每注期望约0.3366元，完整返还还取决于三个浮动奖。至少中1基本号的随机概率约87.96%，中1–3个基本号并不中奖。因此“至少中1号达100%”不能证明选号有效。

在这几个乐透彩种中，它的头奖概率相对较高，但中奖总频率较低。奖金池和历史实发数据会变，不能据某日小奖池永久判定其性价比最差。现有预测也不能支持这类排序。

## 历史预测的适用边界

修复前的位置型数据被排序，且同期开奖的多个模型输出相互相关。旧命中率、基于这些输出的 z 检验和“显著优于/差于随机”的结论不能证明预测能力。修复后重新抓取原始顺序、训练、预测并积累逐期样本，旧记录隔离保存。乐透彩种也不能把“至少中一个号码”当成实际中奖率。

## 长期维护

本文为规则说明，不随每日 Actions 覆盖。规则、派奖或奖金表可能变更，应按官方公告的生效期版本更新。奖金为税前规则金额；浮动奖金和特别活动不能视为固定回报。复式只是购买多注组合，在奖金结构不变时不改善单位成本的数学期望。
