# 7星彩（QXC）规则与分析

依据中国体彩现行7星彩规则。历史曾有旧版七位0–9规则，跨版本回测应按生效期分段，不能视作规则永久不变。

## 号码与投注

前6位各选0–9，最后一位选0–14，共7个有序位置，允许重复。最后一位可为10–14，不能截成两个数字，也不能用统一0–9范围限制它。每注2元，每周二、五、日开奖，支持单式、按位复式及倍投。

复式注数为七个位置候选数量的乘积。原始位置必须从抓取、CSV、训练标签到判奖全程保留，不能对七码整体排序。

## 奖级

下表按最高奖互斥计奖。

| 奖级 | 条件 | 奖金 |
| --- | --- | --- |
| 一等 | 全7位按位相同 | 浮动 |
| 二等 | 前6位全同、末位不同 | 浮动 |
| 三等 | 前6位恰中5位且末位中 | 3000 元 |
| 四等 | 全7位恰中5位 | 500 元 |
| 五等 | 全7位恰中4位 | 30 元 |
| 六等 | 全7位恰中3位，或前6位恰中1位且末位中，或仅末位中 | 5 元 |

一等一般分配浮动奖金90%加奖池，二等10%；开奖前奖池达到3亿元时，分配比例倒置为10%和90%。一二等奖单注最高500万元，并受风险控制规定约束。名义计提奖金50%（49%当期、1%调节基金）。

## 概率与选择依据

总组合数=10⁶×15=15,000,000，一等奖概率1/15,000,000，任一奖约8.1460%，固定奖部分每注期望约0.5358元。每位平均命中的随机基线=(6×0.1+1/15)/7≈9.52%；至少中一位约50.40%。这些命中指标不等于中奖。

旧版“排序后命中率33.33%”不是有效的位置预测结果。即使与某个排序随机基线比较，也不能只凭位置被打乱这一事实就解释额外差异；还存在重复记录、样本相关、基线分布不同等问题。旧z检验撤回，修复后重新累计数据。

偏好小奖频率时可比较该玩法，但较高任一奖概率不等于更高期望净收益，历史实发返奖率也不能代替下一期期望。

## 历史预测的适用边界

修复前的位置型数据被排序，且同期开奖的多个模型输出相互相关。旧命中率、基于这些输出的 z 检验和“显著优于/差于随机”的结论不能证明预测能力。修复后重新抓取原始顺序、训练、预测并积累逐期样本，旧记录隔离保存。乐透彩种也不能把“至少中一个号码”当成实际中奖率。

## 长期维护

本文为规则说明，不随每日 Actions 覆盖。规则、派奖或奖金表可能变更，应按官方公告的生效期版本更新。奖金为税前规则金额；浮动奖金和特别活动不能视为固定回报。复式只是购买多注组合，在奖金结构不变时不改善单位成本的数学期望。
